# 🎓 FORSTUD — Smart Student Management System

## 📌 About The Project

**FORSTUD** is a modern, student-centric web application designed to simplify and organize academic information through a centralized digital platform.

The project provides an intuitive interface where students can explore their academic profiles, monitor attendance, review fee details, and analyze academic performance. Built with HTML, CSS, and JavaScript, FORSTUD focuses on delivering a clean user experience, structured navigation, and interactive student dashboard components.

The platform aims to make academic management more accessible, organized, and engaging through a responsive web interface.

## ✨ Key Features

- **Student Dashboard** — Centralized overview of academic information.
- **Student Profile Management** — Dedicated student profile interface with personal and academic details.
- **Attendance Management** — Attendance summaries and class attendance information.
- **Fee Management** — Semester fee overview, payment summaries, and pending fee information.
- **Performance Analytics** — Academic performance dashboard featuring CGPA, class rank, and subject information.
- **Authentication Interface** — Separate login and registration pages.
- **Responsive Navigation** — Sidebar navigation and interactive menu controls.
- **Modern UI Design** — Clean layouts, typography, icons, and dashboard cards.
- **Theme Customization** — Theme toggle interface for a personalized experience.
- **Modular JavaScript** — Organized JavaScript files for different application sections.

## 🚀 Getting Started

Follow these steps to run FORSTUD locally.

### Prerequisites

- A modern web browser
- Visual Studio Code
- Live Server extension (recommended)

### Installation

**1. Clone the repository**
https://github.com/harshalisharma-806/Student_Profile_Management_System

**2. Navigate to the project directory**

cd STUDENT-PROFILE-MANAGEMENT


**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the application**

Open `index.html` using Live Server or launch it directly in your browser.
